# assets/ — ไฟล์รูปของบริษัท

## logo.png  ← วางไฟล์โลโก้ตรงนี้

โลโก้รวม "แม่ละมาย + Suphan Q Foods" (แนวนอน)

- ชื่อไฟล์ต้องเป็น `logo.png` เป๊ะ (ตัวพิมพ์เล็กทั้งหมด)
- พื้นหลังโปร่งใส (PNG) จะสวยที่สุด เพราะต้องวางบนพื้นทั้งสว่างและมืด
- กว้างอย่างน้อย 1000px เพื่อให้พิมพ์ออกมาคมชัด
- สัดส่วนแนวนอนประมาณ 5:1

วางไฟล์แล้วโลโก้จะขึ้นเองที่:

| ที่ | หมายเหตุ |
|---|---|
| หน้าเข้าสู่ระบบ (คอมพิวเตอร์) | index.html |
| หน้าเข้าสู่ระบบ (มือถือ) | mobile.html |
| หัวใบเบิก / ใบรับ / ใบขอซื้อ / ใบรายงาน / ใบสั่งผลิต | ทำให้ดูเป็นเอกสารของโรงงานจริง |
| ใบ QR ติดบอร์ด | ปุ่ม 🔗 แชร์แอป → 🖨️ พิมพ์ติดบอร์ด |

**ถ้ายังไม่มีไฟล์นี้ ระบบทำงานปกติทุกอย่าง** — แค่ไม่มีโลโก้ขึ้น ไม่มีรูปแตก
