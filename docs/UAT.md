# UAT — ให้คนจริงลองบนเครื่องจริง

ใช้ทุกครั้งที่ปล่อยรุ่นที่เปลี่ยนหน้าตาหรือขั้นตอนทำงาน · ให้คนที่ **ไม่ได้ทำแอป** ลอง (พนักงานหน้างาน / หัวหน้า)
เครื่องตรวจแทนเรื่อง "อ่านออกไหม · งงไหม · ทันงานไหม" ไม่ได้

> ⚠️ ทดสอบบนระบบจริง = ข้อมูลจริง · ใช้รายการที่ตั้งใจเบิกจริงอยู่แล้ว หรือเบิกแล้ว "คืน" ยอดเท่าเดิมทันที
> ห้ามเดาตัวเลขลงข้อมูลจริง (เคยทำยอดเพี้ยน +5,000)

## รอบล่าสุด: หน้าคอม — ตรวจหน้าตา (audit 2026-10-19, รุ่น v90)

ผู้ลอง: ____________ · เครื่อง/จอ: ____________ · วันที่: ____________

### รับ / เบิก
- [ ] เปิดแอปบนคอม → มุมล่างหน้าเข้าระบบขึ้น "รุ่น v90" (ถ้ายังเป็นรุ่นเก่า ปิดแล้วเปิดใหม่อีกครั้ง)
- [ ] กด **รับ / เบิก** ที่รายการไหนก็ได้ → ปุ่ม "เบิก / คืน / รับ" อ่านออกชัดทั้ง 3 ปุ่ม (ไม่จางจนนึกว่ากดไม่ได้)
- [ ] พิมพ์จำนวน → ปุ่มสีเขียวด้านล่างเปลี่ยนเป็น "📤 เบิก … (หน่วย)" ตรงกับที่พิมพ์
- [ ] กด "คืน" → ปุ่มเปลี่ยนเป็น "↩️ คืน …" · กด "รับ" → "📥 รับ …"
- [ ] บันทึกแล้วมีแถบเขียว "บันทึกสำเร็จ" มุมจอ อ่านออก

### นับ
- [ ] กด **นับ** → หน้าต่างแถบสีฟ้าอมเขียว ปุ่ม "ยืนยันยอดจริง" สีเขียว
- [ ] กดยืนยันโดยไม่พิมพ์อะไร → มีข้อความแดงใต้ช่องบอกให้พิมพ์ยอด
- [ ] ปุ่ม "ยกเลิก ✕" มองเห็นชัด กดแล้วปิด

### ฟอร์มและอื่นๆ
- [ ] กด **แก้ไข** → คลิกที่ชื่อช่อง (เช่น "จุดสั่งซื้อเพิ่ม") แล้วเคอร์เซอร์เข้าช่องนั้น
- [ ] ข้อความตัวอย่างในช่องว่าง (เช่น "เช่น 16*48+5") อ่านออก
- [ ] **ห้องเย็น → คงเหลือ**: ป้าย "หมดอายุ" แดง · "ใกล้หมดอายุ" เหลือง · "ปกติ" เขียว
- [ ] **🔗 แชร์แอป** และ **📜 ของฉัน**: หัวหน้าต่างสีเขียวเข้ม (ไม่ใช่ม่วง/ฟ้า)
- [ ] ถ้ามีแท็บเล็ตหรือโน้ตบุ๊กจอเล็ก: หน้าวัตถุดิบเป็นการ์ด ปุ่ม "รับ / เบิก" อยู่ในจอ ไม่ต้องเลื่อนข้าง

### มือถือ (พนักงานหน้างาน + หัวหน้า — ลองบนมือถือของตัวเอง · หน้าตาใหม่แบบป้ายเซฟตี้โรงงาน 2026-10-19)
- [ ] หน้าเลือกคลัง: แผ่นป้าย 3 คลัง สีโรงงาน (ส้ม SQF · เขียว MLM · ฟ้าเขียว ห้องเย็น) อ่านชัดกลางแดด
- [ ] หัวจอเขียวมีแถบเหลือง ชื่อคลังตัวใหญ่ "วัตถุดิบ SQF / วัตถุดิบ MLM / ห้องเย็น SQF" — รู้ทันทีว่าอยู่คลังไหน · ปุ่ม "‹ คลัง" กลับหน้าเลือกคลัง
- [ ] ป้ายหน้ารายการเข้าใจเองโดยไม่ต้องถาม: วงกลมขีดแดง = หมด/หมดอายุ · สามเหลี่ยมเหลือง = ต้องสั่ง/ใกล้หมดอายุ · วงกลมน้ำเงิน = ไม่อัปเดต ช่วยนับ · สี่เหลี่ยมเขียว = ปกติ
- [ ] เปิดคลังแล้วตัวที่ต้องจัดการ (แดง/เหลือง) อยู่บนสุด — ช่วยหรือทำให้หาของยากขึ้น?
- [ ] ช่อง "เลือกสินค้า" และ "ค้นหา" แตะโดนง่าย ไม่ต้องเล็ง · พิมพ์แล้วจอไม่ซูมเอง (iPhone)
- [ ] ไอคอนบนปุ่ม (เบิก/คืน/รับ/นับ, เมนูล่าง, หน้าเลือกคลัง) ดูออกว่าคืออะไรโดยไม่ต้องอ่าน
- [ ] ตัวกรองใต้ช่องค้นหา "หมด/หมดอายุ · ต้องสั่ง/ใกล้หมดอายุ · ไม่อัปเดต" ตรงกับป้ายในรายการ
- [ ] แตะของ → เบิก → ปุ่มล่างสีส้ม "เบิก … (หน่วย)" ตรงกับจำนวน · ปุ่ม "✕ ปิด" แตะง่าย · รับ = ปุ่มเขียว · นับ = ปุ่มฟ้าเขียว
- [ ] ปิดเน็ตแล้วเบิก: มีแถบเหลืองลายเทปกั้น "งานค้างในเครื่อง" เหนือรายการ · เปิดเน็ตแล้วหายเอง
- [ ] หน้า "📈 ต้องสั่ง" และ "📜 ของฉัน" ตัวหนังสือเล็กอ่านได้โดยไม่ต้องซูม
- [ ] ห้องเย็น → แตะสินค้า → "รับเข้า Lot ใหม่": ช่องวันที่แตะง่าย · ปุ่ม "‹ กลับ เลือก Lot" แตะง่าย
- [ ] "🔗 แชร์แอป" ขึ้น QR (เดิมบางเครื่องขึ้น "สร้าง QR ไม่สำเร็จ")
- [ ] หน้า "🔍 ตรวจข้อมูล" (คอม แอดมิน/หัวหน้า): ไม่มีคำว่า "สูตร" — ใช้ "ข้อมูลอ้างอิง"
