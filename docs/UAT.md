# UAT — ให้คนจริงลองบนเครื่องจริง

ใช้ทุกครั้งที่ปล่อยรุ่นที่เปลี่ยนหน้าตาหรือขั้นตอนทำงาน · ให้คนที่ **ไม่ได้ทำแอป** ลอง (พนักงานหน้างาน / หัวหน้า)
เครื่องตรวจแทนเรื่อง "อ่านออกไหม · งงไหม · ทันงานไหม" ไม่ได้

> ⚠️ ทดสอบบนระบบจริง = ข้อมูลจริง · ใช้รายการที่ตั้งใจเบิกจริงอยู่แล้ว หรือเบิกแล้ว "คืน" ยอดเท่าเดิมทันที
> ห้ามเดาตัวเลขลงข้อมูลจริง (เคยทำยอดเพี้ยน +5,000)

## รอบล่าสุด: หน้าคอมแบบป้ายความปลอดภัยโรงงาน ธีม เขียว-ส้ม-ขาว (P2 2026-10-20, รุ่น v93)

ผู้ลอง: ____________ · เครื่อง/จอ: ____________ · วันที่: ____________

### หน้าตาโดยรวม
- [ ] เปิดแอปบนคอม → มุมล่างหน้าเข้าระบบขึ้น "รุ่น v93" (ถ้ายังเป็นรุ่นเก่า ปิดแล้วเปิดใหม่อีกครั้ง)
- [ ] หน้าเข้าระบบ/เลือกโหมด: พื้นเทาอ่อน การ์ดขาวกรอบเขียว (ไม่ใช่พื้นกรมท่าเข้มแบบเดิม)
- [ ] แถบเมนูเขียว มีแถบ **ส้ม** ขอบล่าง · แถวบน = 3 คลัง (ตัวใหญ่) · แถวล่าง = เครื่องมือ ซ้าย "จัดการ" / ขวา "ของฉัน-แอป"
- [ ] ไม่มี emoji แทนไอคอนบนปุ่ม/เมนู — เป็นไอคอนเส้นแบบเดียวกับมือถือ
- [ ] หน้าต่างทุกบาน (แก้ไข ลงทะเบียน ตั้งค่าแจ้งเตือน ของฉัน แชร์แอป …) เป็นแผ่นขาว กรอบเขียว แถบส้มด้านบน หัวขาวตัวเข้ม

### ตารางวัตถุดิบ
- [ ] คอลัมน์สถานะมี **ป้ายรูปทรง** + คำ: วงกลมขีดแดง = หมด/หมดอายุ · สามเหลี่ยมเหลือง = ต้องสั่ง/ต่ำ/ใกล้หมดอายุ · สี่เหลี่ยมเขียว = ปกติ — แบบเดียวกับมือถือ
- [ ] ไม่มีแถบสีขอบซ้ายของแถวแล้ว
- [ ] ปุ่มในแถวมี 3 ปุ่ม **อยู่บรรทัดเดียว ชิดขวาตรงกันทุกแถว**: รับ / เบิก (เขียว) · นับ · แก้ไข — ไม่มีปุ่ม "ลบ" ติดปุ่ม "นับ" แล้ว
- [ ] ชิปกรองมีป้ายรูปทรงเล็กหน้าคำ · แถวบน = ช่องค้นหา + ค่าเตือน · แถวล่าง = ชิปกรอง
- [ ] ปุ่ม "เพิ่มเติม" แบ่งเป็น 3 กลุ่ม: ส่งออก / เอกสาร-พิมพ์ / ข้อมูล · ชื่อไม่ซ้ำกัน ("ใบรายงานสต๊อกคงเหลือ" กับ "ตรวจใบเบิกรายเดือน")

### รับ / เบิก
- [ ] กด **รับ / เบิก** → ปุ่ม "เบิก / คืน / รับ" ตัวที่เลือกเป็นพื้นสีงาน (เบิกส้ม · คืนฟ้า · รับเขียว) ตัวขาว
- [ ] พิมพ์จำนวน → ปุ่มยืนยันด้านล่าง **สีเดียวกับงาน** อ่านทวน "เบิก … (หน่วย)" ตรงกับที่พิมพ์
- [ ] กด "คืน" → ปุ่มยืนยันเป็นสีฟ้า "คืน …" · กด "รับ" → สีเขียว "รับ …"
- [ ] บันทึกแล้วมีแถบเขียว "บันทึกสำเร็จ" มุมจอ อ่านออก

### นับ
- [ ] กด **นับ** → ปุ่ม "ยืนยันยอดที่นับได้" สีฟ้าอมเขียว (สีงานนับ)
- [ ] กดยืนยันโดยไม่พิมพ์อะไร → มีข้อความแดงใต้ช่องบอกให้พิมพ์ยอด
- [ ] ปุ่ม "ยกเลิก" มองเห็นชัด กดแล้วปิด

### ใบขอซื้อ = ตัวเลขชุดเดียวกับจอวางแผนสั่งซื้อ (v95)
- [ ] เปิด **วางแผนสั่งซื้อ** จดจำนวน "แนะนำสั่ง" ของ 2–3 รายการ → ปิด → **เพิ่มเติม → ใบขอซื้อ** (ไม่ติ๊กอะไร) → ช่อง "สั่งจริง" ต้องเท่ากับที่จดไว้ทุกตัว
- [ ] รายการในใบขอซื้อ = รายการ "ต้องลงมือ" ของจอวางแผน (สั่งไม่ทัน / ต้องสั่งวันนี้ / ใกล้ถึงเวลาสั่ง) + ของหมดอายุ · ช่องเหตุผลใช้คำเดียวกับจอวางแผน
- [ ] แก้ตัวเลขช่องสั่งจริง → ช่อง "พอใช้อีกกี่วัน (รวมที่สั่ง)" เปลี่ยนตาม · ตัวที่สั่งตามแนะนำควรขึ้นประมาณ รอของ + สั่งให้พอใช้ + กันชน (ค่าตั้งต้น 7 + 30 + 3 = 40 วัน)

### แก้ไข / ยกเลิกการใช้
- [ ] กด **แก้ไข** → คลิกที่ชื่อช่อง (เช่น "จุดสั่งซื้อเพิ่ม") แล้วเคอร์เซอร์เข้าช่องนั้น · ปุ่ม "บันทึกการแก้ไข" สีเขียว
- [ ] ท้ายหน้าต่างแก้ไขมีลิงก์แดง "ยกเลิกการใช้วัตถุดิบนี้" → ถามยืนยัน → รายการหายจากคลัง ตัวเลข "ยกเลิกการใช้" เพิ่ม 1 (**ลองกับรายการทดสอบเท่านั้น**)
- [ ] ข้อความตัวอย่างในช่องว่าง (เช่น "เช่น 16*48+5") อ่านออก
- [ ] **ห้องเย็น → คงเหลือ**: ป้าย "หมดอายุ" แดง · "ใกล้หมดอายุ" เหลือง · "ปกติ" เขียว · ช่อง QC มีป้ายรูปทรง + คำ
- [ ] ถ้ามีแท็บเล็ตหรือโน้ตบุ๊กจอเล็ก: หน้าวัตถุดิบเป็นการ์ด 3 ปุ่มกว้างเท่ากันเต็มแถว ไม่ต้องเลื่อนข้าง

### หน้าคอม: ตัวเลขตรงกัน + ไม่มีป๊อปอัปบังงาน (critique 2026-10-20)
- [ ] เปิดแอป/รีโหลด: **ไม่มีป๊อปอัปเตือนเด้ง** · หน้าแรกมีแผง "ต้องจัดการ … รายการ" (ป้ายสามเหลี่ยมเตือน) ใต้การ์ดคลัง · แตะคลังในแผงแล้วเข้าไปทำงานได้เลย
- [ ] ตัวเลขแดงบนการ์ดหน้าแรกและบนเมนูขึ้นทันทีหลังรีโหลด และไม่หายเอง
- [ ] ตารางวัตถุดิบ: "พอใช้อีก N วัน" ตรงกับจอวางแผนสั่งซื้อ และตรงกับมือถือ (ตัวเลขเดียวกัน ทศนิยมเหมือนกัน)
- [ ] คำสถานะในตาราง: หมดอายุ / หมดแล้ว / สั่งวันนี้ก็ไม่ทัน / ต้องสั่งวันนี้ / ต่ำกว่าจุดสั่งซื้อ / ใกล้หมดอายุ / ใกล้ถึงเวลาสั่ง / ปกติ — ไม่มี "วิกฤต / เร่งด่วน / ควรสั่ง" แล้ว · ของใกล้หมดอายุไม่ถูกเรียกว่าต้องสั่ง

### มือถือ (พนักงานหน้างาน + หัวหน้า — ลองบนมือถือของตัวเอง · หน้าตาใหม่แบบป้ายเซฟตี้โรงงาน 2026-10-19)
- [ ] หน้าเลือกคลัง: แผ่นป้าย 3 คลัง สีโรงงาน (ส้ม SQF · เขียว MLM · ฟ้าเขียว ห้องเย็น) อ่านชัดกลางแดด
- [ ] หัวจอเขียวมีแถบส้ม (ธีม เขียว-ส้ม-ขาว · 2026-10-20) ชื่อคลังตัวใหญ่ "วัตถุดิบ SQF / วัตถุดิบ MLM / ห้องเย็น SQF" — รู้ทันทีว่าอยู่คลังไหน · ปุ่ม "‹ คลัง" กลับหน้าเลือกคลัง
- [ ] ป้ายหน้ารายการเข้าใจเองโดยไม่ต้องถาม: วงกลมขีดแดง = หมด/หมดอายุ · สามเหลี่ยมเหลือง = ต้องสั่ง/ใกล้หมดอายุ · วงกลมน้ำเงิน = ไม่อัปเดต ช่วยนับ · สี่เหลี่ยมเขียว = ปกติ
- [ ] เปิดคลังแล้วตัวที่ต้องจัดการ (แดง/เหลือง) อยู่บนสุด — ช่วยหรือทำให้หาของยากขึ้น?
- [ ] ช่อง "เลือกสินค้า" และ "ค้นหา" แตะโดนง่าย ไม่ต้องเล็ง · พิมพ์แล้วจอไม่ซูมเอง (iPhone)
- [ ] ไอคอนบนปุ่ม (เบิก/คืน/รับ/นับ, เมนูล่าง, หน้าเลือกคลัง) ดูออกว่าคืออะไรโดยไม่ต้องอ่าน
- [ ] ตัวกรองใต้ช่องค้นหา "หมด/หมดอายุ · ต้องสั่ง/ใกล้หมดอายุ · ไม่อัปเดต" ตรงกับป้ายในรายการ
- [ ] แตะของ → เบิก → ปุ่มล่างสีส้ม "เบิก … (หน่วย)" ตรงกับจำนวน · ปุ่ม "✕ ปิด" แตะง่าย · รับ = ปุ่มเขียว · นับ = ปุ่มฟ้าเขียว
- [ ] ปิดเน็ตแล้วเบิก: มีแถบเหลืองลายเทปกั้น "งานค้างในเครื่อง" เหนือรายการ · เปิดเน็ตแล้วหายเอง
- [ ] หน้า "📈 ต้องสั่ง" และ "📜 ของฉัน" ตัวหนังสือเล็กอ่านได้โดยไม่ต้องซูม
- [ ] ห้องเย็น → แตะสินค้า → "รับเข้า": ช่องวันที่แตะง่าย · ปุ่ม "‹ กลับ เลือก Lot" แตะง่าย
- [ ] **ห้องเย็นรับเข้าวันผลิตเดิม = บวกเพิ่ม** (2026-10-20): รับของ 2 รอบวันผลิตเดียวกัน → ยอดล็อตรวมกัน ไม่ทับ · ก่อนกดเห็น "มีล็อตวันผลิตนี้อยู่ X → รับเข้าแล้วรวม Y"
- [ ] ห้องเย็นเบิก/นับ: ก่อนกดเห็น "เบิกแล้วล็อตนี้เหลือ …" / "ในระบบ X → นับได้ Y (±)" · เบิกเกินขึ้นแดง
- [ ] หน้าคอม ห้องเย็น → นับสต๊อก: ต้องเลือก "📥 รับเข้า" หรือ "📊 นับ" ก่อน · ปุ่มบันทึกทวน "รับเข้า 12 ถ้วย" / "บันทึกยอดนับ 12 ถ้วย"
- [ ] "🔗 แชร์แอป" ขึ้น QR (เดิมบางเครื่องขึ้น "สร้าง QR ไม่สำเร็จ")
- [ ] หน้า "🔍 ตรวจข้อมูล" (คอม แอดมิน/หัวหน้า): ไม่มีคำว่า "สูตร" — ใช้ "ข้อมูลอ้างอิง"
