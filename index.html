LINE กลุ่ม

กำลังตรวจ…

ส่งเฉพาะ สรุปสต๊อก ตามวัน/เวลา/หัวข้อใน กำหนดการส่งสรุป ด้านล่าง (+ ปุ่มส่งในหน้าวางแผนสั่งซื้อ) · LINE นับโควตาตามจำนวนสมาชิกในกลุ่ม — แพ็กเกจฟรี 300 ข้อความ/เดือน

วิธีตั้งค่าครั้งแรก (ทำครั้งเดียว ~10 นาที)
  1. สร้าง LINE Official Account ที่ manager.line.biz (ใช้บัญชี LINE ของเจ้าของ)
  2. ใน LINE Official Account Manager: ตั้งค่า → Messaging API → เปิดใช้งาน · ตั้งค่าการตอบกลับ → ปิดข้อความตอบกลับอัตโนมัติ · ตั้งค่าบัญชี → อนุญาตให้เข้าร่วมแชทกลุ่ม
  3. ที่ developers.line.biz → channel ของบัญชีนี้: คัดลอก Channel secret (แท็บ Basic settings) และกด Issue Channel access token (แท็บ Messaging API) → วางสองช่องด้านบน → บันทึก LINE
  4. แท็บ Messaging API: วาง Webhook URL ด้านบน → กด Verify → เปิด Use webhook
  5. เชิญบัญชีนี้เข้ากลุ่ม LINE — บอทจะตอบในกลุ่มว่า "เชื่อมแล้ว" แล้วกด ทดสอบส่ง

กำหนดการส่งสรุป

เลือกวัน เวลา หัวข้อ และรูปแบบข้อความของแต่ละช่องแยกกัน — LINE นับโควตาตามจำนวนสมาชิก จึงตั้งให้ส่งน้อยวันกว่า Telegram ได้ · กด ดูตัวอย่างก่อนบันทึกได้ (ไม่ส่งจริง)
